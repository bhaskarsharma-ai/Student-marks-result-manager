# Student Marks & Result Manager

A beginner Python project that calculates and displays a student's marks, total, average, highest and lowest marks, and final result.

## Features

- Takes student name as input
- Takes marks for 5 subjects
- Calculates total marks
- Calculates average
- Finds highest and lowest marks
- Shows Pass/Fail result
- Displays the result in a clean format

## Concepts Used

- Variables
- Data Types
- Input and Output
- Type Conversion
- Strings
- Lists
- Tuples
- List Methods
- f-Strings
- Basic Python Calculations

## How to Run

1. Download or clone this repository.
2. Open the Python file in VS Code.
